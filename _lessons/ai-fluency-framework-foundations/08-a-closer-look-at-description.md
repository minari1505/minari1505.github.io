## 학습 목표

- 내 의도를 AI system에 **효과적으로 전달**하는 방법 이해하기
- 명확하고 목적 있는 소통이 왜 중요한지 알아보기
- 세 가지 Description — **Product · Process · Performance** — 기술 기르기

## 한눈에 보는 흐름

<ol class="oa-flow">
  <li><strong>Product</strong>무엇을 만들어 주길 원하나</li>
  <li><strong>Process</strong>어떤 방식으로 접근하길 원하나</li>
  <li><strong>Performance</strong>협업하는 동안 어떻게 행동하길 원하나</li>
</ol>

이 레슨을 한 문장으로 줄이면: **AI는 내 마음을 읽지 못하니, 결과물 · 방법 · 태도를 말로 알려 줘야 해요.**

## 1. Description이란

<div class="oa-eli">
  <span class="oa-eli__head">💇 쉽게 말하면</span>
  <p>미용실에서 "알아서 해 주세요"라고 하면 결과는 운이에요. <b>원하는 스타일(결과물), 자르는 방식(과정), 상담 방식(태도)</b>을 말해 줘야 마음에 드는 머리가 나와요.</p>
</div>

Description은 단순히 프롬프트를 쓰는 일이 아니라, 나와 AI가 **함께 잘 일할 수 있는 협업 환경을 만드는 일**이에요.

<div class="oa-vs">
  <div class="oa-vs__bad">
    <span class="oa-vs__label">❌ AI를 이렇게 대하면</span>
    <ul>
      <li>검색어만 넣으면 답이 나오는 <b>데이터베이스</b></li>
      <li>버튼만 누르면 나오는 <b>자판기</b></li>
    </ul>
  </div>
  <div class="oa-vs__good">
    <span class="oa-vs__label">✅ 이렇게 대해요</span>
    <ul>
      <li>주고받으며 일하는 <b>상호작용하는 파트너</b></li>
      <li>처음에 명확하게 전달하면 시간도 아끼고 결과도 좋아져요</li>
    </ul>
  </div>
</div>

## 2. 세 가지 Description

<div class="oa-cards">
  <div class="oa-card"><span class="oa-card__icon">📦</span><span class="oa-card__title">Product Description</span>AI가 <b>무엇을 만들지</b> 명확히 정의 — 결과물, 형식, 독자, 스타일</div>
  <div class="oa-card"><span class="oa-card__icon">🧭</span><span class="oa-card__title">Process Description</span>AI가 요청에 <b>어떻게 접근할지</b> 안내 — 최종 목표만큼 중요할 수 있어요</div>
  <div class="oa-card"><span class="oa-card__icon">🎭</span><span class="oa-card__title">Performance Description</span>협업 중 AI가 <b>어떻게 행동할지</b> 정의 — 간결/상세, 도전적/지지적</div>
</div>

같은 요청에 세 가지를 더하면 이렇게 달라져요.

| | 막연한 요청 | Description을 더한 요청 |
|---|---|---|
| **Product** | "발표 자료 만들어 줘" | "신입 사원 대상, 10분 분량, 슬라이드 5장 개요로 만들어 줘" |
| **Process** | (없음) | "먼저 핵심 메시지 3개를 뽑고, 그다음 슬라이드별로 배치해 줘" |
| **Performance** | (없음) | "논리가 약한 부분은 솔직하게 지적하고, 답은 간결하게 해 줘" |

*(표의 예시 문장은 이해를 돕기 위한 예시예요.)*

- 지금 AI와 대화할 때 Product · Process · Performance 중 무엇을 놓치고 있나요?

## 정리

- **Description**은 생산적인 협업 환경을 만드는 방식으로 AI와 소통하는 것이에요.
- **Product**: 결과물 · 형식 · 독자 · 스타일 등 원하는 것을 명확히 정의해요.
- **Process**: AI가 요청에 접근하는 방식을 안내해요. 최종 목표만큼 중요할 수 있어요.
- **Performance**: 간결/상세, 도전적/지지적 같은 행동 방식을 정해요.
- AI는 데이터베이스나 자판기가 아니라 **상호작용하는 파트너**예요.
- 처음에 명확히 소통하면 **시간을 아끼고 더 좋은 결과**를 얻어요.
