## 2. 지금 생성형 AI의 한계

<div class="oa-eli">
  <span class="oa-eli__head">📰 쉽게 말하면</span>
  <p>아주 똑똑하지만 <b>어느 날 이후로 신문을 못 본 사람</b>이고, 모르는 것도 <b>자신 있게 말할 때가 있고</b>, 책상이 좁아 한 번에 펼칠 수 있는 서류에 한도가 있어요.</p>
</div>

| 한계 | 뜻 | 사람이 할 일 |
|---|---|---|
| **지식 컷오프 (knowledge cutoff)** | 학습이 끝난 시점 이후의 정보를 몰라요 | 최신 정보는 직접 제공하거나 확인 |
| **환각 (hallucination)** | 사실과 다른 내용을 그럴듯하게 낼 수 있어요 | 중요한 사실은 검증 |
| **Context window 제약** | 한 번에 다룰 수 있는 정보량에 한도가 있어요 | 필요한 맥락을 골라서 제공 |
| **복잡한 추론의 어려움** | 여러 단계의 까다로운 추론에서 실수할 수 있어요 | 추론 과정을 살펴보고 판단 |

> 이 분야는 **빠르게 진화**하고 있어요. 능력과 한계의 목록은 고정된 게 아니라 "지금 시점"의 스냅숏이에요.

## 정리

- 생성형 AI는 기존 데이터를 분석하는 것을 넘어 **새 콘텐츠**를 만들어요.
- 현대 LLM은 **transformer 아키텍처 · 방대한 학습 데이터 · 급증한 연산 능력**으로 가능해졌고, **pre-training → fine-tuning** 두 단계로 배워요.
- **능력**: 작업 간 다재다능함, 대화 인식, 외부 도구 연결.
- **한계**: 지식 컷오프, 환각, context window 제약, 복잡한 추론의 어려움.
- 가장 효과적인 활용은 **사람의 비판적 사고·판단·창의성·윤리적 감독 + AI의 강점**이에요.
