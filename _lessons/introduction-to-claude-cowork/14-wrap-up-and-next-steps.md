## 2. 이번 주 해볼 것 (하나 고르기)

<div class="oa-eli">
  <span class="oa-eli__head">🏊 쉽게 말하면</span>
  <p>수영 강습을 다 들었어도 <b>물에 들어가야</b> 수영이 늘어요. 다섯 가지를 다 하려 하지 말고, 이번 주에 하나만 물에 담가 보세요.</p>
</div>

| 고를 것 | 무엇을 하나 |
|---|---|
| **memory 설정** | 다섯 문장짜리 global instructions를 쓰거나, 이미 하고 있는 작업 흐름에 project 하나 만들기 |
| **작업 예약, 또는 휴대폰에서 시작하기** | 반복 결과물을 주기(cadence)에 올리기. 또는 다음에 업무 외 시간에 뭔가 떠오르면 휴대폰의 Claude 앱에서 Cowork에 넘기기 |
| **plugin 설치** | Customize → Plugins에서 내 역할에 가장 가까운 것을 설치해 이번 주 작업에 실행하기 |
| **Claude in Chrome 또는 M365 써보기** | 실제 작업이 가장 많이 일어나는 surface를 골라 설치하고 한 작업에 사용하기 |
| **만든 것 공유** | 유용했던 사용 사례 · 좋은 결과를 낸 워크플로 · 직접 만든 skill을 팀과 공유하기. 동료가 Claude와 편해지는 계기가 될 수 있어요 |

처음 정리할 때 강의는 두 번째 항목을 "작업 예약 또는 Dispatch 설정"으로 안내했어요. 현재 강의는 Dispatch 대신 "휴대폰에서 시작하기"로 설명해요.

## 정리

- Cowork 강의는 **Meet → Make Yours → Everywhere → Sharing & Safety**의 흐름으로, "실제 작업 위임"이라는 하나의 줄기 위에 쌓였어요.
- 다음 단계는 완벽한 이해가 아니라 **이번 주에 하나**(memory · 예약 또는 휴대폰에서 시작 · plugin · Chrome/M365 · 공유)를 실제로 해보는 거예요.
- 더 깊이 가려면 **AI Fluency, AI Capabilities and Limitations, Claude 101**로 이어 가면 좋아요.
- 다음에 무엇을 맡길지 막막하면 **Claude use-case library**를 Cowork로 필터해 봐요.
