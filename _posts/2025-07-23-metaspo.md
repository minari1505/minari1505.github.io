> 📄 **Paper**: [arXiv:2505.09666](https://arxiv.org/abs/2505.09666)

## 세 줄 요약

- 기존 prompt 최적화는 user prompt만 다뤘지만, 이 논문은 **system prompt**에 집중해요.
- **MetaSPO**는 여러 작업과 prompt에서 두루 잘 작동하는 system prompt를 자동으로 만들어요.
- 메타러닝으로 학습하고, 14개 작업에서 일관되게 높은 성능을 보였어요.

## 배경

- LLM이 하는 작업이 복잡할수록, user prompt만으로는 모델의 행동을 원하는 방향으로 제어하기 어렵다고 느꼈어요.
- user prompt보다 근본적으로 모델의 성격을 정하는 **system prompt**를 최적화하는 방법을 찾다가 읽었어요.

## 기존 방식의 한계

- user prompt는 일반화가 어려워요. 작업마다 새 user prompt를 만들어야 해요.
- prompt가 길어질수록 유지보수와 관리가 어려워요.

## MetaSPO

![MetaSPO 개요]({{ '/assets/images/papers/metaspo/overview.png' | relative_url }})

- 다양한 작업(task)과 user prompt에 일반화되는 system prompt를 자동으로 최적화하는 **meta-learning framework**예요.
- user prompt와 system prompt를 함께 고려하는 **bilevel 최적화** 구조예요.

## 최적화 과정

![MetaSPO bilevel 최적화]({{ '/assets/images/papers/metaspo/bilevel.png' | relative_url }})

하위 수준 최적화 → 상위 수준 최적화를 번갈아 반복해요.

**하위 수준 (Inner loop): system prompt는 고정, user prompt를 task별로 최적화**

1. user prompt로 Q-A 쌍에 대한 응답을 만들고, 틀린 응답을 모아요.
2. LLM이 틀린 응답의 문제를 진단하고 개선된 user prompt를 만들어요.
3. 후보 중 성능이 가장 높은 k개를 골라 `U_i`로 저장해요.
4. 모든 task T1~Tn에 대해 반복해서 U1~Un을 얻어요.

**상위 수준 (Outer loop): 여러 user prompt에 대해 system prompt를 최적화**

1. 각 task `T_i`에 가장 잘 작동한 `U_i`를 지정해요.
2. (system prompt, `U_i`) 쌍으로 응답을 만들고, 틀린 응답을 모아요.
3. LLM이 문제를 진단하고 개선된 system prompt를 만들어요.
4. 후보 중 성능이 가장 높은 k개를 골라 저장해요.

이 과정을 반복하면서 점점 더 일반화된 system prompt를 학습해요.

## 실험 결과

5개 도메인(의료, 리뷰, 논리 추론, 안전성, 정답 근거), 14개 task로 평가했어요.

**1. Unseen Generalization (처음 보는 작업으로의 일반화)**

최적화된 system prompt를, 학습 때 보지 않은 task와 user prompt에 그대로 썼을 때 얼마나 잘 작동하는지 평가해요.

![Unseen generalization 결과]({{ '/assets/images/papers/metaspo/unseen.png' | relative_url }})

- 처음 보는 여러 task에서 다른 방식보다 일관되게 높은 성능을 보였어요.

**2. Test-Time Adaptation (테스트 시점 적응)**

system prompt는 그대로 두고, 새 작업의 user prompt만 몇 개 예시로 추가 최적화할 때 얼마나 효율적인지 평가해요.

![Test-time adaptation 결과]({{ '/assets/images/papers/metaspo/test-time-adaptation.png' | relative_url }})

- 기본 system prompt 대비 같은 성능을 **데이터 75% 적게, 최적화 반복 80% 적게** 달성했어요.

## 결론

- system prompt를 반복적으로 개선하면서, 각 작업의 user prompt와 시너지를 내는 방식으로 학습해요.
- 그래서 기존 방식이 못 풀던 **여러 작업에 대한 일반화 부족 문제**를 넘어서고, **system prompt 하나로 여러 task를 처리하는 실용적인 방법**을 제시해요.
- gradient-free 방식이라 폐쇄형 API 기반 LLM에도 쓸 수 있어요.

**잘 맞는 경우**

- 다양한 user prompt를 다뤄야 하는 multi-turn 환경
- 사용자 지시가 없어도 모델의 성격을 일관되게 유지하고 싶을 때

**아쉬운 점**

- 메타러닝 구조라 반복 학습 비용이 다소 높을 수 있어요.
- system prompt가 길어지면 inference latency가 늘 수 있어요.
