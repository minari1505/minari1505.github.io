### 세 줄 요약

- 기존 프롬프트 최적화는 ‘user prompt’만 다뤘지만, 이 논문은 ‘system prompt’에도 집중함
- MetaSPO는 다양한 작업과 프롬프트에도 잘 작동하는 ‘강력한 시스템 프롬프트’를 자동으로 생성함
- 메타러닝을 활용해 학습하고, 14개 작업에서 일관되게 높은 성능을 보임

### 배경

- LLM이 수행하는 작업이 복잡할수록, user prompt만으로는 모델의 행동을 원하는 방향으로 제어하기 어렵다고 느꼈습니다.
- user prompt보다 근본적으로 모델의 성격을 조정하는 ‘system prompt’를 최적화하는 방법을 찾다, 해당 논문을 읽게 되었습니다.

### 기존 방식의 한계

- user prompt는 일반화가 어려움. 매 작업마다 새롭게 user prompt를 만들어야함
- prompt가 길어질수록 유지보수 & 관리하기가 어려워짐

### MetaSPO

![]({{ '/assets/images/papers/metaspo/overview.png' | relative_url }})

- 다양한 작업(task)와 user prompt에 일반화 가능한 sytem prompt를 자동으로 최적화하는 meta-learning framework
- user prompt & system prompt를 동시에 고려하는 bilevel 최적화 구조를 지님

### 실험 과정

![]({{ '/assets/images/papers/metaspo/bilevel.png' | relative_url }})

- 하위수준 최적화 → 상위수준 최적화를 반복 진행
  - 하위 수준(Inner loop) : system prompt는 고정. user prompt를 task-specific하게 최적화
    - user prompt을 적용, Q-A 쌍에 대한 응답 생성 → 잘못된 응답 모음
    - LLM이 잘못된 응답의 문제 진단 → 개선된 user prompt 생성
    - 다양한 후보들 중 성능이 가장 높은 k개를 선택 →’Ui’로 저장
    - 모든 task T1~Tn에 대해 반복해 U1~Un을 얻음
  - 상위 수준(Outer loop) : 다양한 user prompt에 대해 system prompt의 성능을 최적화
    - 각 task ‘Ti’에 대해 가장 잘 작동한 ‘Ui’를 지정
    - (system prompt, Ui)쌍으로, 질문에 대한 응답 생성 → 틀린 응답들을 모음
    - LLM이 잘못된 응답의 문제 진단 → 개선된 system prompt 생성
    - 다양한 후보들 중 성능이 가장 높은 k개를 선택 → ‘Si’로 저장

- 이 과정을 반복적으로 수행해 점점 더 일반화 가능한 system prompt를 학습함

### 실험 결과

- 총 5개 도메인(의료, 리뷰, 논리 추론, 안정성, 정답 근거), 14개 task

**[검증 방법]**

1. Unseen Generalization(미학습 일반화)
   - 최적화된 system prompt가 한 번 만들어지면, 이전에 보지 않은 다양한 task, user prompt에도 얼마나 잘 작동하는 지 평가

     ![]({{ '/assets/images/papers/metaspo/unseen.png' | relative_url }})

     - 다양한 unseen task에서 다른 방식들보다 일관되게 높은 성능을 보임
2. Test-Time Adaptation(테스트 시점 적응)
   - 최적화된 system prompt는 그대로 두고, 새로운 작업에 대한 user prompt를 몇가지 예시만 가지고 추가로 최적화할 때 얼마나 효율적인지 평가

     ![]({{ '/assets/images/papers/metaspo/test-time-adaptation.png' | relative_url }})

     - default에 비해 동일한 성능을 75% 적은 데이터로, 80% 적은 최적화 반복으로 달성함 → 빠르고 효율적인 적용 가능

### 결론

- MetaSPO는 sytem prompt를 반복적으로 개선하면서 각 작업에 필요한 user prompt들과의 시너지를 내는 방식으로 학습
- 이를 통해 기존 접근들이 해결하지 못했던, **다양한 작업에 대한 일반화 성능 부족 문제를 극복**하고, **하나의 system prompt로 여러 task를 효과적으로 처리할 수 있는 실용적인 해법**을 제시함
- gradient-free 방식을 적용함으로써 폐쇄형 API 기반 LLM에도 적용 가능하다는 점에서 활용 범위가 넓음

장점

- 다양한 user prompt를 다뤄야하는 multi-turn
- 사용자의 지시 없이도 일관된 모델의 성격을 유지하고 싶은 경우 유용할 것

단점

- 메타러닝 구조 자체가 반복적인 학습 과정을 거치므로 학습 비용이 다소 높을 수 있음
- system prompt의 길이가 길어지는 경우 inference latency가 늘어날 수 있음
