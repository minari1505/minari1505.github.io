## 논문 선정 이유

고객사 PoC - ‘신규 디자인 화합물 특허성 확보’

- 사용자가 화합물을 입력, 해당 화합물을 특허로 등록할 수 있는지 질의
- 분자의 특성을 넣고, 해당 특성을 가진 새로운 화합물 생성 질의

과정에서 활용할 수 있을 것 같아 해당 논문을 읽게 되었습니다.

- 분자 생성(Molecule Generation) ↔ 분자 특성 예측(Molecule Property Prediction)
  - 분자 구조 문자열(SMILES), 화학적 특성(Property Vector)를 각각의 인코더를 통해 임베딩 벡터로 변환, 트랜스포머 퓨전 인코더를 통해 통합

### SMILES란?

- 분자 구조를 문자열로 표현한 것

  ![]({{ '/assets/images/papers/spmm/smiles.png' | relative_url }})

  - 이중결합 : =, 삼중결합 : #, 사중결합 : \$
  - 고리 : 랜덤한 한 지점의 결합을 끊고, 끊긴 부분의 원자 두개에 번호 표기

    ![]({{ '/assets/images/papers/spmm/smiles-ring.png' | relative_url }})

  - 방향족 : 고리와 동일하지만, B,C,N,O,P,S는 소문자로 표시

    ![]({{ '/assets/images/papers/spmm/smiles-aromatic.png' | relative_url }})

  - 가지 : 괄호로 표현. 괄호가 끝나고 나오는 첫번째 원자는 같은 원자에 결합되어있음

    ![]({{ '/assets/images/papers/spmm/smiles-branch.png' | relative_url }})

  - 표기 순서

    ![]({{ '/assets/images/papers/spmm/smiles-order.png' | relative_url }})

    1. 분자로부터 수소 원자 제거
    2. 고리에 있는 결합을 하나씩 제거하고, 고리마다 번호 매기기

       ![]({{ '/assets/images/papers/spmm/smiles-order-2.png' | relative_url }})

    3. 특정 원자를 정하고, 해당 원자로부터 DFS. 나머지는 가지라고 생각하고 표기

       ![]({{ '/assets/images/papers/spmm/smiles-order-3.png' | relative_url }})

    4. SMILES 도출

       ![]({{ '/assets/images/papers/spmm/smiles-order-4.png' | relative_url }})

### PV란?

- Property Vector, 한 분자의 화학적 특성들을 줄세운 것.
- 분자량, 소수성, 극성 표면적, 고리 수, 방향족 고리 수, 수소 결합 공여자 수, 독성 여부, 약물 유사도 등등
  - PV = \[78.1, 2.3, 45.0, 2, 1, 0, 0.89, ...\]

## SPMM method

### 1. Training

![]({{ '/assets/images/papers/spmm/training.png' | relative_url }})

- 분자 구조, 분자 성질 데이터를 각각의 encoder로 학습 ⇒ 정보를 섞어 서로의 관계를 학습
- PV / SMILES encoder는 transformer encoder와 유사한 구조를 사용
- Fusion Encoder
  - cross attention 연산으로 PV ↔ SMILES 정보의 관계성을 섞어줌
- Next Word / Property Prediction을 위한 Regression, classification layer를 거쳐 학습 진행

### 2. transformer로 처리하기 위한 전처리

![]({{ '/assets/images/papers/spmm/embedding.png' | relative_url }})

- transformer와 유사하게 처리하기 위해서는 분자 구조(SMILES), 특성 벡터(PV)를 언어와 유사한 구조로 변형해주는 작업이 필요함(Embedding)

\[SMILES\]

- 분자 구조를 영문+숫자로 변환해놓은 데이터
- 이미 문자로 이루어져있으므로, 기존의 word embedding + positional encoding 방식 사용

\[PV\]

- 특성’값’을 저장해놓은 벡터
- 특성값이 Linear Layer를 거쳐 Embedding으로 매핑 + positional encoding
- 학습과정에서 약 50%를 마스킹 처리(Unknown 변환)해 Augmentation 진행.
  - ‘특성값 → 분자 구조 생성’ 하는 업무에서, 일부 특성값이 ‘unknown’일 수밖에 없음.
    - ex) 질량 1g을 만족하고, 밀도는 알아서 정한 분자 구조 만들어줘
  - 이런 부분을 대응하기 위해 학습단계부터 ‘unknown’ 입력값 추가

### 3. Loss funtion

**\[Constrastive Loss\]**

- SMILES, PV 각각 출력된 CLS 토큰 (전체 시퀀스의 요약 벡터)에 contrastive loss 적용 → 같은 샘플의 SMILES, PV간은 가깝게, 다른 샘플간은 멀게 학습
- Similarity
  1. Inter Modal Similarity : 매칭되는 SMILES, PV간(Modality 간) 가까워지도록 당겨줌

     ![]({{ '/assets/images/papers/spmm/inter-modal.png' | relative_url }})

  2. Intra Modal Similarity : 나 이외의 다른 SMILES, PV는 멀어지도록 밀어줌

     ![]({{ '/assets/images/papers/spmm/intra-modal.png' | relative_url }})

  - 1,2 의 n,m : modality 별 배치 사이즈

**\[Next Word/Property Prediction Loss\]**

- SMILES, PV 각각의 예측 학습을 위한 loss
- SMILES : Next word 예측 → Cross Entropy 사용
  - 문자 단위 토큰 시퀀스이므로 cross entropy 사용
- PV : Next Property Value 예측 → MSE 사용
  - 실수값 벡터이므로 MSE 사용

**\[SMILES PV Matching Loss\]**

- SMILES, PV가 매칭되면 1, 아니면 0으로 학습 → SMILES, PV간 관계 학습

### 4. Inference

1. PV → SMILES generation
   - 분자가 갖고있어야할 성질(PV)를 정해두고, 해당 조건을 만족하는 새로운 화합물 구조 생성하는 경우
   - PV 입력받아 분자 구조 생성
   - fusion encoder부터 상위 layer는 모두 SMILES 것으로 사용
   - 생성되는 output은 다시 SMILES encoder 입력으로 들어감

   ![]({{ '/assets/images/papers/spmm/pv-to-smiles.png' | relative_url }})

2. SMILES → PV generation
   - 화합물의 구조를 입력하고 해당 화합물이 어떤 성질을 가질 지 예측
   - fusion encoder부터 상위 layer는 모두 PV 것으로 사용
   - 생성되는 output은 다시 PV encoder 입력으로 들어감

   ![]({{ '/assets/images/papers/spmm/smiles-to-pv.png' | relative_url }})

## 장단점

**\[장점\]**

1. PV ↔ SMILES 간 양방향 예측 가능
2. 일반화 능력
   1. 50%의 특성벡터를 마스킹해 학습하여, 데이터 증강과 유사한 효과를 발휘했음
3. 다양한 downstream task에 적용 가능. 별도의 추가학습 없이 특성 예측, 분자 생성, 반응 예측 등 화학적 문제 해결 가능

**\[단점\]**

1. 데이터가 많이 필요
   1. 학습 시 PV, SMILES 데이터가 모두 필요함
2. 2D정보만 반영
   1. 3D 구조 정보를 충분히 반영하지 못하고 있음 → 입체화학은 해결하지 못함
