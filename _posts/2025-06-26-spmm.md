> 📄 **Paper**: [Nature Communications (2024)](https://www.nature.com/articles/s41467-024-46440-3)

## 논문 선정 이유

화합물 특허 검토 PoC에서 "구조를 넣으면 특성을 예측"하고 "특성을 넣으면 구조를 제안"하는 두 방향의 질의를 다뤄야 했어요. 이 논문은 그 두 방향을 **모델 하나**로 처리해서 읽게 됐어요.

## 핵심: 두 modality를 하나의 모델로

분자를 두 가지로 표현하고, 각각을 별도 인코더로 임베딩한 뒤 fusion encoder로 합쳐요.

| Modality | 정체 | 예시 |
|---|---|---|
| **SMILES** | 분자 구조를 문자열로 적은 표기법. 원자·결합·고리·가지를 문자와 숫자, 괄호로 표현 | 문자 토큰 시퀀스 |
| **PV (Property Vector)** | 분자 특성값(분자량, 극성 표면적, 고리 수 등)을 한 줄로 나열한 실수 벡터 | `[78.1, 2.3, 45.0, 2, 1, 0, 0.89, ...]` |

구조 문자열은 "언어"처럼, 특성 벡터는 "수치 시퀀스"처럼 다루는 **멀티모달 transformer**라고 보면 돼요. 이미지-텍스트 모델(CLIP, ALBEF 등)의 구조를 분자 도메인으로 옮긴 셈이에요.

## SPMM 방법

### 1. 학습 구조

![SPMM 학습 구조]({{ '/assets/images/papers/spmm/training.png' | relative_url }})

- SMILES encoder와 PV encoder가 각자 표현을 학습해요. 둘 다 transformer encoder와 비슷한 구조예요.
- **Fusion Encoder**가 cross-attention으로 두 표현의 관계를 섞어요.
- 그 위의 head로 next token / next property prediction을 학습해요.

### 2. 임베딩

![SPMM 임베딩]({{ '/assets/images/papers/spmm/embedding.png' | relative_url }})

- **SMILES**: 이미 문자열이라 일반적인 word embedding + positional encoding을 그대로 써요.
- **PV**: 각 특성값을 linear layer로 embedding에 매핑하고 positional encoding을 더해요.
- 학습 중 PV의 **약 50%를 마스킹**(unknown 처리)해요. 실제 사용할 때는 일부 특성값만 지정하고 나머지는 모르는 경우가 많아서, 학습 단계부터 그 상황에 대비하는 거예요. 데이터 증강 효과도 있어요.

### 3. Loss

| Loss | 목적 |
|---|---|
| **Contrastive Loss** | 두 인코더의 CLS 벡터를 비교해, 같은 분자의 SMILES·PV는 가깝게, 다른 분자끼리는 멀게. modality 간(inter)과 modality 내(intra) 유사도를 모두 사용 |
| **Next Token Prediction** | SMILES는 문자 토큰이라 Cross Entropy |
| **Next Property Prediction** | PV는 실수값이라 MSE |
| **SMILES–PV Matching** | 둘이 짝이면 1, 아니면 0으로 분류해 관계를 학습 |

### 4. Inference: 양방향

| 방향 | 동작 |
|---|---|
| **PV → SMILES** | 특성 조건을 입력하면 fusion encoder 위쪽은 SMILES 쪽 head를 써서 구조 문자열을 autoregressive하게 생성 |
| **SMILES → PV** | 구조를 입력하면 PV 쪽 head를 써서 특성값을 하나씩 예측 |

## 실험 결과

![생성 평가 지표]({{ '/assets/images/papers/spmm/metrics.png' | relative_url }})

생성 품질은 세 지표로 봐요.

- **Validity**: 생성된 문자열 중 문법적으로 유효한 비율
- **Uniqueness**: 유효한 결과 중 서로 겹치지 않는 비율
- **Novelty**: 그중 학습 데이터에 없던 비율

조건을 주는 방식에 따라 결과가 이렇게 달라졌어요.

- **특성 전체 지정**: 생성 결과의 특성이 입력값에서 크게 벗어나지 않았어요.
- **일부만 지정**: 지정한 특성은 입력값 근처에 모이고, 나머지는 다양하게 분포했어요.
- **모두 unknown**: 특성이 고르게 퍼지도록 다양한 결과가 나왔어요.

→ 50% 마스킹 학습 덕분에 **부분 조건**에서도 자연스럽게 동작해요.

## 장단점

**장점**

1. 구조 ↔ 특성 양방향 예측을 모델 하나로 해요.
2. 마스킹 학습 덕분에 일반화가 잘 돼요.
3. 추가 학습 없이 특성 예측, 생성 등 여러 downstream task에 쓸 수 있어요.

**단점**

1. 학습에 구조와 특성 데이터가 모두 필요해서 데이터가 많이 들어요.
2. 문자열(2D) 표현만 써서 3D 구조 정보는 담지 못해요.

## 정리

도메인은 화학이지만, 구조만 보면 **"두 modality를 contrastive + cross-attention으로 정렬하고, 마스킹으로 부분 조건 입력을 지원하는 멀티모달 transformer"**예요. 표 데이터(수치 벡터)와 텍스트를 함께 다루는 다른 문제에도 참고할 만한 설계예요.
